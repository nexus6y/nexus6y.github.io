An AI-powered CLI and web tool that uses the Claude API to analyze academic paper abstracts. Simply provide a paper title and abstract, and the assistant generates:

- **One-sentence summary** of the paper
- **Key contributions** extracted from the abstract
- **Methodology** breakdown
- **Potential future work** suggestions
- **Keywords** for categorization

Built with Python, Gradio, and the Anthropic Claude API.
